### Production authentication URL

`AUTH_URL` must be the canonical HTTPS domain currently attached to this Vercel project. After changing it, redeploy production and verify from a cookie-free request that a protected route redirects to `/login` on the same host and that the login page returns HTTP 200. Do not point it at a planned domain until Vercel domain attachment and DNS are both verified.

Server-generated invoice and packing links use `NEXT_PUBLIC_APP_URL`, then `AUTH_URL`/`NEXTAUTH_URL`, and finally Vercel's injected production host. Production fails closed if none is available; there is no hard-coded legacy-domain fallback.
