# Oportunidades de listas

1. Abre **Analítica → Oportunidades de listas**.
2. Sube el archivo recibido por WhatsApp (`XLS`, `XLSX`, `XLSM`, `CSV` o `TXT`) o pega el mensaje.
3. Presiona **Analizar contra IMPORTSYS**.
4. Revisa primero **Oferta probable** y **Posible oferta**.
5. Antes de comprar, confirma modelo, capacidad, región, color, condición y cantidad; revisa manualmente los resultados **Ambiguo** o **No encontrado**.

La comparación usa el historial disponible de compras y ventas. Es informativa y no modifica datos en IMPORTSYS.
